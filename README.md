# 💰 급여 주기 가계부 (PWA)

급여일(기본 25일, 공휴일/주말 시 전 영업일) 기준으로 예산 주기를 계산하는 오프라인 우선 PWA입니다.

## 핵심 기능

- **급여일 기준 주기 계산**: 25일 입금 → 다음 25일 입금 전일까지의 주기
- **월급 자동 반영**: 설정한 월급과 급여일을 다음 급여일부터 적용하며, 과거 급여는 유지
- **월급 수정**: 급여 입력에서 금액만 입력해 현재 선택한 주기의 월급을 수정
- **고정지출 관리**: 월세·적금 등을 매월 반복 등록하고, 체크해 예정/완료 상태 관리
- **지출 영역 분리**: 고정지출과 일반 지출을 별도 목록으로 구분
- **공휴일/주말 자동 조정**: 한국 공휴일 반영, 전 영업일로 자동 이동
- **D-Day 카운트다운**: 다음 급여일까지 남은 일수
- **오프라인 지원**: Service Worker로 네트워크 없이 사용 가능
- **데이터 로컬 저장**: localStorage 기반, 서버 불필요
- **다크모드 자동 지원**

## 파일 구조

```
├── index.html      # 메인 화면
├── style.css       # 스타일 (다크모드 포함)

└── sw.js           # Service Worker
```

## 로컬 실행

PWA는 HTTPS 또는 localhost에서만 동작합니다.

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# PHP
php -S localhost:8080
```

브라우저에서 `http://localhost:8080` 열기

## 사용법

1. **설정**: 월급과 급여일(기본 25일) 입력. 변경 사항은 다음 급여일부터 적용
2. **월급 수정**: 급여 입력/수정에서 금액만 입력해 선택한 주기의 월급 수정
3. **지출 추가**: 항목, 금액, 날짜, 카테고리를 입력하고 필요하면 매월 반복 설정
4. **예정 지출 체크**: 예정 항목을 납부·이체한 뒤 체크해 완료 처리
5. **주기 잔액 확인**: 상단에서 남은 예산 확인
6. **주기 초기화**: 새 급여 주기 시작 시 사용

## 계산 로직

```
주기 M = [M월 급여일, (M+1)월 급여일 전일]

예: 2026년 1월 급여일 = 1/25(일) → 1/23(금) 대체 지급
    → 1월 주기: 2026.01.23 ~ 2026.02.24 (1/23 급여로 쓸 수 있는 기간)
    → 2월 급여일: 2/25(수)
    → 2월 주기: 2026.02.25 ~ 2026.03.24

· 모든 날짜는 정확히 1개 주기에 속함 (공백/중복 없음, 연도 경계 포함)
· 1월 1일~22일은 2025년 12월 주기(2025.12.24 ~ 2026.01.22)에 속함
```

**D-Day** = 다음 급여일까지 남은 일수 (3일 이하 적색 표시)

## 커스터마이징

### 공휴일 추가
`app.js` 상단 `HOLIDAYS` 객체에 연도별 날짜 추가:

```js
2028: [
  '2028-01-01', '2028-02-15', // ...
]
```

### 급여일 변경
UI에서 10일/15일/20일/25일을 선택할 수 있습니다. 코드에서 기본값 변경:

```js
payDay: 25,  // state 기본값
```

## 데이터 관리

- **저장 위치**: `localStorage` 키 `paycycle_data_v2`
- **초기화**: 브라우저 개발자도구 → Application → Local Storage → 삭제
- **백업**: 위 키의 JSON 값을 복사하여 저장

## 주의사항

- 공휴일은 2025-2027년 하드코딩. 이후 연도는 직접 추가 필요
- localStorage는 브라우저별 5~10MB 제한 (수년치 사용 가능)
- 여러 기기에서 사용 시 데이터 동기화 불가 (서버 백엔드 추가 필요)
